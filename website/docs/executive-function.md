# Executive Function Skills for Emotional and Social Moments

Emotional and social skills often require remembering tools, practicing scripts, noticing patterns, preparing for hard conversations, and repairing later. Executive function helps make those social tools easier to find when emotions are high.

This page is the local doorway into the Literacy for Kids [Executive Function Toolkit](https://www.literacy-for-kids.com/docs/toolkits/executive-function), connected to the emotional and social skills this curriculum builds.

## A few core ideas

- **Social skills can need reminders and practice plans.** A tool you cannot find in the moment cannot help.
- **Boundary scripts are easier to use when practiced before the hard moment.** Rehearse when calm.
- **Repair can need a next-step plan.** "What is one thing I will do to fix this?"
- **Unsafe social situations need trusted adult help.** Some things are not a kid's job to manage alone.

## When this shows up

- When remembering a coping tool is hard
- When preparing a boundary sentence
- When planning a repair
- When a group project has roles
- When tracking trust or patterns over time
- When a situation feels unsafe or too big

## Tools that help

- **Script practice checklist** — rehearse the sentence a few times.
- **Restart after a hard moment** — a short plan to come back.
- **Trust pattern tracker** — what has this person shown me more than once?
- **Repair next-step card** — one concrete step.
- **Trusted adult help** — for anything unsafe or too big.

:::tip Executive Function Moment
A social script is easier to use if you practice it before the hard moment. Write one sentence you might need, then keep it somewhere easy to find. Future-you deserves a cue.
:::

:::caution Everyday task skills, not a diagnosis
These are everyday planning and task-management tools, not therapy, medical advice, disability evaluation, ADHD treatment, or a replacement for trusted adults, educators, caregivers, or qualified support. Kids should not be expected to manage unsafe social situations alone. If a situation feels unsafe, threatening, or too big, involve a trusted adult right away.
:::
